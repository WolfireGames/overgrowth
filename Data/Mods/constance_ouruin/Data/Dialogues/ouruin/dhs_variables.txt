== LETHALITY
	At the end of every level, Ouruin adds up each elimination, kill and overkill.
	These variables are then tallied to form a total number of points.
	This point total is compared to a percentage of the maximum possible lethality points (not counting throats slit and overkills).

	(0) Perfect Non-Lethal Stealth requires 0% lethality points.
	(1) Non-Lethal Stealth requires less than 10% lethality points.
	(2) Non-Lethal requires less than 25% lethality points.
	(3) Lethal requires less than 50% lethality points.
	(4) Full-Lethal requires more than 75% lethality points.
	(5) Perfect Full-Lethal requires 100% lethality points.
	(6) Senseless Full-Lethal requires more than 100% lethality points.

	-- Totals
	ouruin_total_eliminations
	ouruin_total_kills
	ouruin_total_overkills
	ouruin_total_lethality
		Tallied at the end of each level, averaged with every level's lethality state
	ouruin_total_alerts

	-- Levels (Replace level with level name)
	ouruin_level_eliminations
		Adds 1 lethality point
	ouruin_level_kills
		Adds 8 lethality points
	ouruin_level_zonekills
		Adds 2 lethality points. Incurred upon drowning, dying to spikes, or lava
	ouruin_level_overkills
		Adds 2 lethality points per overkill. Maximum of 10 overkills per level. Multiple overkills can be achieved on the same character
	ouruin_level_throatscut
		Adds 4 lethality points
	ouruin_level_lethality
		Tallies up every lethality point, and decides a level's final lethality state (PNLS, NLS, NL, L, FL, PFL, SFL). Only set at the end of the level
	ouruin_level_alerts
		Does not affect lethality

		ouruin_cinderian_alerts
			Tallies up alerts from each Cinderbreathe occupied level.
		ouruin_snakes_alerts
			Tallies up alerts from each Snake occupied level.
		ouruin_rats_alerts
			Tallies up alerts from the Rat Den.

	-- Suffixes
		_current: Count on this current level playthrough. Does not apply to ouruin_level_lethality
		_stored: Added to _current. Modified on checkpoints, so counts from previous areas still apply. Does not apply to ouruin_level_lethality
		_points: Only set at the end of the level. Points of lethality earned per variable
